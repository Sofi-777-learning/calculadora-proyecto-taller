# Calculadora de Gastos Personales

Aplicación de consola en Python para registrar y controlar gastos personales.

## Descripción
Este proyecto permite:
- Registrar gastos con descripción, monto y categoría.
- Ver el listado completo de gastos registrados.
- Calcular el total gastado.
- (Próximamente) Generar un reporte de gastos agrupados por categoría.

## Cómo ejecutar
```bash
python main.py
```
